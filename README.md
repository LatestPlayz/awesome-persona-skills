## 📖 About this application

awesome-persona-skills provides a collection of persona files to enhance your AI interactions. These files help your chatbot simulate specific roles, such as a colleague, a manager, an ex-partner, or a version of yourself. These profiles influence how your software responds to your prompts. You gain better control over your chat sessions by applying these pre-set personas.

## 🛠️ System requirements

This application runs on Windows 10 and Windows 11. Your computer requires at least 4GB of RAM to process these skills smoothly. You do not need specialized hardware or graphic cards to use this tool. Ensure you have a stable internet connection for the initial setup.

## 🚀 How to use your skills

1. Open the application from your desktop icon.
2. Navigate to the Skills library tab in the main menu.
3. Browse the available persona files. These include specialized options like colleague.skill, boss.skill, ex.skill, and self.skill.
4. Click the Add button next to your chosen persona to import it into your workspace.
5. Open your chat interface or connected AI tool.
6. Select the imported persona from the dropdown list.
7. Send a message to the AI. It will respond using the tone and logic defined in your selected persona file.

## 💡 Managing your personas

You can switch between different personas at any time. If you want to stop using a specific role, simply uncheck it in the library tab. You can add as many personas as your computer storage allows. The application saves your preferences, so you do not need to re-import files after you close and reopen the program.

## 🔍 Troubleshooting common issues

If the application fails to open, ensure you have the latest updates for your Windows system. Sometimes, antivirus software blocks new files. If your antivirus reports an issue, check your history logs and mark the program as a safe file.

If a persona file does not load, verify that the file remains in the original folder where you saved it. Moving or deleting files after import causes errors. If you delete a file, return to the library screen and re-import the file from your download folder.

## 📂 Understanding your skill files

Each file carries a .skill extension. These files contain instruction sets for your AI. When you select boss.skill, the software adjusts the vocabulary and professional tone of the AI to reflect a management perspective. When you select self.skill, it learns from your writing patterns to mimic your own style. These files operate like templates for the software to use during your chat sessions. You may create folders to organize your skills if your library grows too large. Simply drag and drop the files in the library view to shift them between categories.
